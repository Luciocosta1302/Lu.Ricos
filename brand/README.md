# Identidade LU.RICOS

| Papel | Nome | Hex | Quanto usar |
| --- | --- | --- | --- |
| Base | Aço escovado | `#e9eae6` | fundos, a maior parte |
| Texto e contraste | Grafite | `#111214` | textos, faixas escuras |
| Destaque | Vermelho Estojo | `#cc2744` | pouco: o ponto da marca, um selo, um botão |
| Destaque em texto pequeno | Vermelho Estojo escuro | `#a81d35` | rótulos vermelhos sobre o aço |

- **Assinatura:** o ponto de LU.RICOS é sempre vermelho.
- **Regra do destaque:** no máximo um elemento vermelho por peça, além do ponto.
- **Fontes:** Archivo expandida (títulos, caixa alta), Instrument Sans (texto), Martian Mono (preços e códigos).
- **Fotos:** sempre as fotos reais das peças. O forro vermelho das caixas já conversa com o destaque.

Arquivos: `logo-lu-ricos-grafite.png` (fundo claro), `logo-lu-ricos-claro.png` (fundo escuro), `avatar-lu-ricos.png` (perfil do Instagram).

**Foto de perfil (`avatar-lu-ricos-mostrador.png`):** um mostrador com LR no centro, em que o ponto vermelho do logo é o 12. Feito para o recorte redondo do Instagram e para ser reconhecido mesmo pequeno.

## Símbolos (`simbolos/`)

O nome LU.RICOS, com o ponto vermelho, não muda. Estes são três símbolos de forma própria para o perfil, os posts e os vídeos. Cada um tem a versão de perfil (`perfil-*.png`, 1080 × 1080) e a animação vertical para reels e stories (`animacao-*.mp4`, 1080 × 1920, 4,5 s).

| Símbolo | Ideia |
| --- | --- |
| Coroa | A caixa do relógio vista de cima; a coroa (o botão de acertar a hora) é o ponto vermelho |
| Etiqueta | A etiqueta de preço da loja; o furo do barbante é o ponto vermelho |
| Monograma | O R apoiado no pé do L; o ponto vermelho fecha a linha de baixo |

Os desenhos e as animações estão em `marks.js` e `marks.css`.

## Identidade em serifa (`serifa/`)

Escolhida a partir do catálogo de estilos: o nome em Bodoni Moda com o ponto vermelho quadrado, e o símbolo dos ponteiros às 3 horas formando o L (haste grossa, pé fino, como o L da Bodoni).

| Arquivo | Uso |
| --- | --- |
| `perfil-ponteiros.png` | Foto de perfil recomendada (1080 × 1080) |
| `perfil-lr.png` | Foto de perfil alternativa, LR em serifa |
| `nome-grafite.png`, `nome-claro.png` | O nome com fundo transparente, para fundo claro e escuro |
| `nome-*-com-cidade.png` | O nome com "Relógios · Marabá" embaixo |
| `abertura-serifa.mp4` | Abertura para reels e stories (1080 × 1920, 5,5 s) |

Os desenhos e as animações estão em `marks.js` e `marks.css`.
